# Sagu Innovation Lab

Platform eksplorasi bahan sagu — permainan mencampur bahan untuk menemukan produk.

## Cara menjalankan

1. Clone repo
2. `npm install`
3. Salin `.env.example` jadi `.env.local`, isi `DEEPSEEK_API_KEY`
4. `npm run dev`

## Fitur

- 40 bahan (5 dasar sagu + 35 tambahan)
- 33 produk dengan resep
- Drag & drop bahan ke wadah racik
- Animasi jelly + efek sihir
- AI (DeepSeek) untuk kombinasi baru
- Sound efek sintetis
- Mode sesi + rekap temuan

## Teknologi

- Vite + React + TypeScript
- Tailwind CSS v4
- @dnd-kit/react
- Framer Motion
- Zustand
- DeepSeek API
